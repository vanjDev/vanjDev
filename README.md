## Building now

- **[byvanj bot](https://bot.byvanj.com)** — a no-code Discord bot builder with a web dashboard and a Go runtime for running multiple bots.
- **[byvanj.com](https://byvanj.com)** — my interactive portfolio and project index, built with React, TypeScript, and Three.js.

## Selected work

- **[OptiMD](https://github.com/vanjDev/OptiMD)** — turns long PDF and DOCX files into structured Markdown packages with chunks, images, tables, and traceable source files.
- **[SOLAR Evaluation Helper](https://github.com/vanjDev/solar-survey-helper)** — fills supported evaluation controls in Chrome while leaving submission in the user's hands.
- **[ThesisBot](https://github.com/vanjDev/ThesisBot)** — brings thesis tasks, deadlines, notes, and reminders into Discord and a local dashboard.
